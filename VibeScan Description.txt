1. VibeScan — pre-deploy security scanner for solo AI-coded SaaS

Core Value Proposition
92% of US developers now use AI coding assistants, and 25% of the last YC batch shipped codebases that are 95%+ AI-generated. AI-generated code carries 2.74x more security flaws than human-written code — one scan of 5,600 live vibe-coded apps found 2,000+ high-impact vulnerabilities and 400 exposed secrets in production. Every existing security-scanning vendor (Snyk, Semgrep's own paid tier, enterprise AppSec platforms) is built and priced for a security team, not a solo founder who vibe-coded a SaaS in a weekend and has no idea what a "leaked service-role key" even means. The pain is acute and immediate: these builders are about to charge customers a credit card and have zero idea their Supabase key is sitting in a public GitHub repo. That's not a "nice to have" — it's "someone will drain my Stripe account tonight."

Zero-Cost Tech Stack
- Wrap existing free/open-source scanners: Gitleaks (secrets), Semgrep OSS rules, npm audit/pip-audit — all free, all mature, zero licensing cost.
- Ship as a GitHub Action + a thin web dashboard (Next.js on Vercel free tier, Supabase free tier for storage).
- The differentiator over raw Gitleaks/Semgrep output is an LLM triage layer: pipe raw findings into an LLM API to rank by actual exploitability and generate a plain-English fix diff — this is the paid layer, and inference cost per scan is fractions of a cent.
- Stripe (free until you transact) for billing, GitHub App OAuth for install — no infra to provision.

Market Validation Signals
Georgia Tech's Vibe Security Radar tracked 35 new CVEs in a single month (March 2026) directly attributable to AI coding tools. The category is being written up in Forbes and CSA research notes as "vibe coding's security debt." Cost to build a functional SaaS has dropped from ~$200K to ~$5K, which means the population of non-technical people shipping production code is growing faster than the population of people who know what a CVE is. Volume of buyers, not sophistication of buyers, is the trend.

Free Distribution Strategy
- Post free one-off scan results (with permission-safe, redacted findings) as build-in-public threads on X/Reddit's r/SaaS, r/indiehackers, r/vibecoding — "I scanned 20 random Product Hunt launches, here's what I found" is a self-propagating format that already worked for security researchers going viral in 2025-2026.
- List the GitHub Action free on the GitHub Marketplace — that's built-in distribution with zero CAC.
- DM the last 30 days of Product Hunt "built with Claude/Cursor/Replit" launches directly; offer a free scan, upsell the paid triage+monitoring tier on the findings call.
- r/vibecoding and Indie Hackers directly reward "I built the fix for the pain everyone's complaining about" posts — don't sell, show the scan.

Monetization & Exit Plan
Freemium: free one-time scan, $19-49/mo for continuous monitoring + AI-generated fix PRs (undercut enterprise AppSec pricing by 10x, which is the whole point). At even 150 subscribers and ~80% margin (inference cost is the only variable cost), that's $2-7K MRR within a couple months of a genuine viral post. Package for exit as an add-on acquisition target for an existing dev-tools company (Vercel, Supabase, or a scanning vendor like Semgrep) who wants the solo-builder segment cheaply — these are exactly the "tuck-in" acquisitions that move fast on Acquire.com. Micro-SaaS in this profile closes in 30-60 days at 2.85-6x annual profit on Acquire.com; a tool solving a fear-driven, quantifiable-loss problem (leaked keys, drained accounts) sells buyers on the story easily.
