# VibeScan

Security scanning for people who didn't write their own code — VibeScan finds the specific mistakes AI coding assistants (Claude Code, Cursor, Replit, Lovable, Bolt) tend to leave in shipped apps: leaked secrets, disabled database security, unverified payment webhooks, and a short list of other high-signal issues — and explains each one in plain English with a suggested fix.
